# Deafest_GreenCircuit_buyer

# 중고 스마트폰 구매자 추천 시스템

Green Circuit **구매자 파트** 프로토타입입니다.

구매자가 원하는 스마트폰 기종과 중요하게 생각하는 성능 3가지를 순서대로 선택하면, **성능·가격 합리성·환경온도**를 종합적으로 평가해 중고 스마트폰 매물을 추천합니다.

> 현재는 샘플 매물 데이터를 사용하는 단계입니다. 실제 판매자 보증서 JSON/DB와의 연결은 추후 통합 작업이 필요합니다.

## 1. 구현 기능

- 스마트폰 기종 검색(공백·영문 대소문자 무시, 부분 일치)
- 카메라, 마이크, 스피커, 자이로, 터치 중 중요 성능 3가지 선택 및 순위 지정
- 선택한 성능 중 60점 미만 항목이 있는 매물 제외
- 성능·가격 합리성·환경온도를 반영한 종합 점수 계산
- 종합 점수순 추천 매물 정렬
- 추천 결과 및 항목별 점수 시각화

## 2. 기술 스택

- **Backend:** JavaScript, Node.js, Express
- **Frontend:** HTML, CSS, JavaScript
- **Data:** `server.js`의 샘플 매물 배열(`LISTINGS`)
- **Gemini API:** 현재 구매자 추천 파트에서는 사용하지 않음 (별도 API 키 불필요)

## 3. 프로젝트 구조

```text
Deafest_GreenCircuit_buyer/
├── server.js          # Express 서버, 추천 알고리즘 및 API
├── static/
│   └── index.html     # 구매자 화면
├── package.json       # npm 의존성/설정
├── package-lock.json  # 의존성 잠금 파일
└── README.md
```

`node_modules/`는 `npm install` 시 자동 생성되므로 GitHub에 올릴 필요가 없습니다.

## 4. 실행 방법

**Node.js와 npm**이 설치되어 있어야 합니다.

프로젝트 폴더에서:

```bash
npm install
```

서버 실행(기본 8000번 포트):

```bash
node server.js
```

- 웹페이지: http://localhost:8000

8000번 포트가 이미 사용 중이라면 macOS/Linux에서:

```bash
PORT=8001 node server.js
```

- 웹페이지: http://localhost:8001
- 서버 종료: 터미널에서 `Ctrl + C`

**참고:** Node.js/Express 프로젝트에는 FastAPI의 `/docs` 자동 API 문서 페이지가 없습니다. API는 아래 요청 예시로 테스트할 수 있습니다.

## 5. 추천 알고리즘

### ① 기종 필터링

입력된 기종과 부분 일치하는 샘플 매물만 선택합니다. 공백과 영문 대소문자는 무시합니다.

### ② 최소 성능 기준

구매자가 고른 3가지 성능이 **모두 60점 이상**인 매물만 남깁니다.

### ③ 성능 점수

선택한 성능 3가지에 다음 가중치를 적용해 가중평균을 계산합니다.

| 우선순위 | 가중치 |
|---|---:|
| 1순위 | 50% |
| 2순위 | 30% |
| 3순위 | 20% |

### ④ 가격 합리성 점수

필터를 통과한 후보 매물들의 **가격 중앙값**을 기준으로 합니다.

- 중앙값의 70% 이하: 100점
- 중앙값의 130% 이상: 0점
- 사이 구간: 선형적으로 계산

### ⑤ 환경온도 점수

현재 공유된 `server.js`에서는 **샘플 환경온도 0~100을 가정**하고 `eco_temp / 100`으로 점수를 환산합니다.

판매자 파트의 보증서 예시에서는 **36.6°C를 시작값**으로 사용하고 있으므로, 실제 연동 시 팀의 환경온도 규칙에 맞춰 샘플 값·점수 환산식·화면 표시를 함께 수정해야 합니다. 현재 코드에 36.6°C 기준이 자동으로 반영된 것은 아닙니다.

### ⑥ 최종 추천 점수

| 평가 항목 | 가중치 |
|---|---:|
| 성능 | 40% |
| 가격 합리성 | 35% |
| 환경온도 | 25% |

각 항목을 0~100점으로 환산한 후 가중합으로 **종합 점수(100점 만점)**를 계산하고 내림차순 정렬합니다. 가중치는 `server.js` 상단에서 변경할 수 있습니다.

## 6. API

### `POST /recommend`

구매자가 선택한 기종과 중요 성능 순위를 받아 추천 결과를 JSON으로 반환합니다.

요청 예시:

```json
{
  "device_model": "갤럭시 S23",
  "priorities": ["camera", "touch", "gyro"]
}
```

macOS/Linux에서 테스트:

```bash
curl -X POST http://localhost:8000/recommend \
  -H "Content-Type: application/json" \
  -d '{"device_model":"갤럭시 S23","priorities":["camera","touch","gyro"]}'
```

8001번 포트로 실행한 경우 요청 URL도 `http://localhost:8001/recommend`로 바꿔 주세요.

응답에 포함되는 데이터:

- `query`: 입력 조건
- `count`: 추천 매물 수
- `items`: 추천 매물 배열 (매물 정보, `final_score`, `breakdown` 포함)
- `breakdown`: 성능(`performance`), 가격(`price`), 환경온도(`eco`) 점수

입력이 잘못되면 **HTTP 422**, 조건에 맞는 매물이 없으면 **HTTP 404**를 반환합니다.

## 7. 현재 구현 상태 및 추후 작업

**구현 완료(샘플 데이터 기준)**

- 구매자 입력 화면 및 추천 결과 화면
- 기종·성능 필터링
- 우선순위 및 가중치 기반 추천 알고리즘
- Node.js/Express `POST /recommend` API

**추후 팀원 간 연동 필요**

- `LISTINGS`를 실제 판매자 보증서/등록 매물 데이터로 교체
- 보증서의 하드웨어 점검 상태(`pass`/`fail` 등)와 현재 0~100점 점수 체계의 연결 기준 확정
- 환경온도의 36.6°C 초기 기준과 추천 점수 환산 방식 통일
- 실제 판매가격과 업체 매입 참고 시세 구분
- 보증서 상세 페이지 연결
- 디자인 담당자가 제작하는 `buyer.html`, 공통 `ui.css`와 통합
- 팀 전체 Node.js 서버에 구매자 API 통합

현재는 **독립 실행 가능한 구매자 추천 프로토타입**이며, 전체 서비스 연동은 완료되지 않았습니다.
