# Deafest_GreenCircuit_buyer

# 중고 스마트폰 구매자 추천 시스템

해커톤 구매자 파트 구현 코드입니다.

구매자가 원하는 스마트폰 기종과 중요하게 생각하는 성능 3가지를 선택하면, **성능·가격 합리성·환경온도**를 종합적으로 평가하여 적합한 중고 스마트폰 매물을 추천합니다.

## 1. 구현 기능

- 스마트폰 기종 검색
- 카메라, 마이크, 스피커, 자이로, 터치 중 중요 성능 3가지 선택
- 선택한 성능의 우선순위 반영 (1~3순위)
- 최소 성능 기준에 미달하는 매물 제외
- 성능·가격·환경온도 기반 종합 점수 계산
- 종합 점수순 추천 매물 정렬
- 추천 점수 및 항목별 점수 시각화

## 2. 기술 스택

- **Backend:** Python, FastAPI, Pydantic
- **Frontend:** HTML, CSS, JavaScript
- **Server:** Uvicorn
- **Data:** 현재 Python 샘플 데이터 사용

별도의 AI API 키 없이 실행할 수 있습니다.

## 3. 프로젝트 구조

```text
devfest/
├── main.py
├── static/
│   └── index.html
└── README.md
```

- `main.py`: FastAPI 서버 및 추천 알고리즘
- `static/index.html`: 구매자 조건 입력 및 추천 결과 화면

## 4. 실행 방법

Python 설치 후 프로젝트 폴더에서 다음 명령어를 실행합니다.

### 라이브러리 설치

```bash
python3 -m pip install fastapi "uvicorn[standard]"
```

### 서버 실행

```bash
python3 -m uvicorn main:app --reload --port 8001
```

브라우저 접속:

- 웹페이지: http://127.0.0.1:8001
- API 테스트: http://127.0.0.1:8001/docs

서버 종료: `Ctrl + C`

## 5. 추천 알고리즘

### ① 기종 필터링

구매자가 입력한 기종에 해당하는 매물을 검색합니다.

공백과 영문 대소문자는 무시하며, 부분 일치를 허용합니다.

### ② 최소 성능 기준

구매자가 선택한 3가지 성능 중 하나라도 60점 미만이면 추천 대상에서 제외합니다.

### ③ 성능 점수 계산

선택한 성능의 우선순위에 따라 가중평균을 계산합니다.

| 우선순위 | 가중치 |
|---|---|
| 1순위 | 50% |
| 2순위 | 30% |
| 3순위 | 20% |

### ④ 가격 합리성 점수

같은 조건을 만족하는 후보 매물들의 가격 중앙값을 기준으로 평가합니다.

- 중앙값의 70% 이하: 100점
- 중앙값의 130% 이상: 0점
- 그 사이: 선형 계산

### ⑤ 환경온도 점수

판매자 환경온도는 36.6°C를 초기 기준으로 사용합니다.

현재는 테스트용 환경온도 데이터를 사용하며, 추천 점수로 변환하는 기준은 추후 팀원과 협의하여 확정할 예정입니다.

### ⑥ 최종 추천 점수

| 평가 항목 | 가중치 |
|---|---|
| 성능 | 40% |
| 가격 합리성 | 35% |
| 환경온도 | 25% |

최종 점수는 100점 만점이며, 점수가 높은 매물부터 추천합니다.

가중치는 `main.py` 상단에서 수정할 수 있습니다.

## 6. API

### POST `/recommend`

구매자가 선택한 기종과 성능 우선순위를 전달하면 추천 결과를 반환합니다.

요청 예시:

```json
{
  "device_model": "갤럭시 S23",
  "priorities": ["camera", "touch", "gyro"]
}
```

응답에는 다음 정보가 포함됩니다.

- 검색 조건 (`query`)
- 추천 매물 개수 (`count`)
- 추천 매물 목록 (`items`)
- 매물별 종합 점수 (`final_score`)
- 성능·가격·환경온도 개별 점수 (`breakdown`)

조건에 맞는 매물이 없으면 HTTP 404를 반환합니다.

## 7. 현재 구현 상태 및 추후 작업

**현재 구현 완료**

- 구매자 입력 UI
- 기종 및 성능 필터링
- 가중치 기반 추천 알고리즘
- 추천 결과 화면
- FastAPI 추천 API

**추후 팀원 간 연동 필요**

- 하드코딩된 `LISTINGS`를 실제 판매자 보증서 데이터로 교체
- 판매자 보증서 JSON의 `pass/fail` 결과를 추천 기준과 연결
- 카메라 성능 등 서로 다른 점수 체계 통일
- 환경온도 계산 기준 통일
- 보증서 상세 페이지 연결
- 실제 등록 매물 가격 및 정보 연동

현재는 **샘플 데이터 기반 프로토타입**이며, 실제 판매자 데이터 및 DB 연동 전 단계입니다.
